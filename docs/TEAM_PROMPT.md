# برومبت الفريق (انسخه كما هو وأرسله لـ Claude مع رابط الريبو)

```text
أنت تنضم لفريق يبني مشروع "Heritage Conservation Copilot": وكيل ذكاء اصطناعي يدعم قرارات ترميم الجدران الطينية في حي الطريف (الدرعية)، ضمن تحدي agentX الرياض.

الريبو: https://github.com/11mayarrr/heritage-conservation-copilot
الفرع الحالي للعمل: mvp (إلى أن يُدمج في main؛ تحقق من ملف الخطة).

قبل أي شيء:
1. اقرأ بالكامل docs/PROJECT_PLAN.md ثم README.md. ملف الخطة هو المرجع الوحيد لما أُنجز وما بقي.
2. لا تكتب كودًا قبل أن تشرح لي.

ثم اشرح لي بالعربي وبلغة بسيطة (أنا قد لا أكون تقنيًا):
أ) فكرة المشروع ومبدأه "الوكيل يقترح والمختص يقرر".
ب) وين وصلنا: ما أُنجز، وما هو تجريبي، وما ينقص، حسب الأقسام 3 و4 و6 من الخطة.
ج) كيف أشغّل المشروع على جهازي خطوة بخطوة: الخلفية ثم الواجهة، مع ذكر مشاكل Windows الشائعة. اسألني عن نظام التشغيل أولًا.
د) النقاط المهمة التي يجب الانتباه لها: القواعد غير القابلة للتفاوض في القسم 2.
هـ) "نقطة الاستئناف" في أعلى الملف: ما المهمة التالية، وما المهام التي يمكنني أخذها بالتوازي.

بعد الشرح:
- اسألني أي مهمة أستلم (اقترح واحدة من نقطة الاستئناف أو مهمة ☐ بلا مسؤول).
- ابدأ العمل من آخر نقطة مسجلة في نقطة الاستئناف، ولا تعد بناء شيء مكتمل.
- اعمل على فرع جديد باسم <رمز-المهمة>-<وصف> وافتح Pull Request. لا تعمل push على main.
- شغّل الاختبارات قبل أي PR: python -m pytest -q tests (وإن تغيرت الواجهة: cd frontend && npm test && npm run build).

قواعد صارمة:
- لا تخترع مراجع أو مصادر أو أرقام دقة. أي رقم دقة لازم يكون محسوبًا على صور حقيقية معتمدة من مختص.
- أي بيانات أو نتائج وهمية أو اصطناعية توسمها بوضوح، ولا تقدمها كنتائج حقيقية.
- الخصوصية: إخفاء الوجوه قبل أي تحليل أو تخزين، ولا حفظ للصور الأصلية.
- المعالجات من المكتبة المغلقة فقط مع المصدر والصفحة والمقتطف.
- إذا كانت معلومة ناقصة تؤثر على الدقة، توقف واسألني بدل التخمين.
- لا تنتقل للمرحلة التالية وفيها خطأ يؤثر على الدقة.

بعد كل مرحلة أو مهمة، وفي نفس الـ PR:
1. حدّث docs/PROJECT_PLAN.md: غيّر ☐ إلى ☑، وحدّث "نقطة الاستئناف"، وأضف سطرًا في "سجل التحديثات"، وأضف أي سؤال جديد للقسم 12.
2. اكتب لي ملخصًا: ما أُنجز، الملفات، الافتراضات، طريقة التشغيل، الاختبارات، الأسئلة المفتوحة، القيود.
```

## ملاحظات لمن يرسل البرومبت
- تأكد أن العضو مضاف للريبو (Settings → Collaborators) إن كان الريبو خاصًا.
- إن كان Claude لا يستطيع فتح GitHub، اطلب من العضو تنزيل الريبو ورفع `docs/PROJECT_PLAN.md` و`README.md` له.
