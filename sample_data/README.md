# sample_data

- `synthetic/` — procedurally generated textures made by `scripts/make_synthetic_samples.py`.
  **Not real walls and not real damage.** Used only to test the pipeline. Do not report results on them.
- `real/` — put real At-Turaif wall photos here (not committed by default). For every photo, record in
  `real/SOURCES.md`: photographer/owner, license or permission, date taken, wall number.
  Photos with people are fine: faces are hidden automatically on upload, but review them anyway.

Tips for usable photos: shoot the wall face-on, in even daylight (no hard shadows), from the same spot
each visit (mark it), include a scale bar or the reference grid if available.
